# SPITE

Futuristic mandalas. Original AI art series by Sirhc, under Circuit Research.

SPITE was born from the anti-AI theft debates: copyright infringement, plagiarism, and theft are three distinct things, and ultimately a human problem.

## The series

**CORE SERIES** — heavy-contour circuit pieces, motherboard and custom-PC-lighting feel. Icy silver-cyan labels.

**PASTEL SERIES** — lighter tones, candy textures, whimsical. Warm cream labels.

## Pieces in this repo

| Piece | File |
| --- | --- |
| CORE #001, perfectly circular concentric circuit disc, cyan and violet neon | `core-series-001-2080-watermarked.jpg` |
| PASTEL #001, "Nebula Bloom", smooth pastel nebula bloom, peach, teal, pink | `pastel-series-001-2080-watermarked.jpg` |

Both are 2080 x 2080 posting versions, watermarked `@circuit_research` diagonally across the centre. Labels are all-caps Kaushan Script, hollow embossed outline, typeset deterministically, never AI-redrawn.

The clean 3840 x 3840 masters stay private and are not in this repo.
